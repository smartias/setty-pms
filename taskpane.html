The Setty PMS add-in has moved

This address no longer hosts the Outlook and Word add-in.

If you are seeing this inside Outlook or Word, your installed add-in is pointing at the old address and needs to be reinstalled. It will not be able to sign in until it is.

What to do

  1. Contact whoever manages the Setty add-in installation and ask for the current manifest.
  2. Remove the existing Setty add-in from Outlook, then install the new manifest.
  3. Sign in again when the task pane opens.

Where it lives now

The add-in is served from its own repository, which holds the manifest, the task pane and the Word surface together:

https://smartias.github.io/setty-pms-addin/taskpane.html

Opening that link directly in a browser will not work. An Office add-in only functions when Outlook or Word loads it through an installed manifest.

For developers

The source of record is smartias/setty-pms-addin. The copy that used to sit here was a stale fork and was never a working deployment: it referenced msal-browser.min.js, which this repository has never contained, so sign-in could not succeed from this address. Edit the add-in in setty-pms-addin only, and remember to bump the taskpane.js?v= cache token when you deploy.
